# Changelog

이 문서는 이번 버전(1.0.0)부터 관리합니다. 그 이전(이슈풀 단독 구현 → 평가사이클/ESRS토픽/이해관계자
추가 → 타사 사례 반영 편의기능 추가)의 반복은 하나로 합쳐 1.0.0의 기반으로 삼았습니다.

## [1.7.0] - 2026-08-14

매트릭스 화면의 카드 순서와 레이아웃을 전면 재구성하고, 좌우 여백을 활용해 한 화면에
최대한 들어오도록 압축했습니다.

### 변경
- 세로 순서를 표본개요→3열카드→결과표로 재배치(직전 버전은 표본개요가 그래프 아래였음)
- 3열 카드를 좌(가중치·임계값) · 중(매트릭스 그래프) · 우(수동 조정, 점 클릭 시 표시)로 배치.
  우측 칸 상단의 "전체 일괄조정" 토글로 지난 버전에서 별도 카드였던 일괄편집 표를 같은 칸
  안에서 전환 표시하도록 변경(세로 섹션 수를 늘리지 않기 위함)
- `app-shell` 최대폭을 1080px→1320px로 확대하고, 카드 패딩·여백·SVG 차트 최대폭을 전반적으로
  축소해 1366×768 해상도에서 툴바+표본카드+3열 카드까지 스크롤 없이 보이도록 개선(결과표는
  내용에 따라 약간의 스크롤 필요)
- 실제 스크린샷으로 레이아웃과 색상 구획을 시각 검증(사분면별 점 위치가 올바르게 표시됨을
  확인), 임시저장 재진입 복원·일괄조정 토글·사유검증·보고서 자동이동 전부 회귀 테스트로 재확인

## [1.6.0] - 2026-08-14

지난 버전의 임시저장/저장은 점 하나씩만 처리했는데, **모든 지점을 한 화면에서 한 번에** 편집하고
한 번의 클릭으로 전체 반영되도록 바꿨습니다. 저장 완료 시 보고서 화면으로 자동 이동합니다.

### 변경
- 매트릭스 화면에 "전체 값 일괄 조정" 표 추가 — 모든 테마그룹의 영향/재무 최종값을 한 화면에서
  동시에 편집
- **전체 임시저장**: 값을 바꾼 지점만 골라 사유 없이 draft로 저장(`db.batchSaveDrafts`)
- **전체 저장 → 보고서로 이동**: 값을 바꾼 지점만 골라 공통 사유로 한 번에 확정 반영
  (`db.batchSaveOverrides`, 사유 없으면 차단), 저장 성공 시 `#/report/:assessmentId`로 자동 이동.
  변경 없이 클릭 시 "변경된 값이 없습니다" 안내, 사유 누락 시 에러 다이얼로그, 정상 케이스에서
  실제로 변경된 건수만 저장되고 보고서 화면으로 이동하는 것을 테스트로 확인

결과 분석·매트릭스 화면 UI/UX 개선 요청을 반영했습니다.

## [1.4.0] - 2026-08-14

참고 이미지(뉴스젤리 설문분석 가이드)의 4가지 시각화 유형을 반영하고, 매트릭스 화면에 표본
개요·표본오차를 추가했습니다.

### 신규
- **문항별 응답분포 시각화**(`#/distribution/:templateId`, 분석 화면에서 링크): 참고이미지와
  동일한 4개 유형을 1~5점 척도에 맞춰 구현
  - 양방향 발산 차트: 전체 문항을 부정(1~2점)/긍정(4~5점) 비율로 한 화면에 비교
  - 막대 차트: 선택한 문항의 점수구간별 응답 수
  - 비율 스택 차트: 선택한 문항의 점수구간별 비율(%)
  - 유닛(도트) 차트: 응답 1건 = 점 1개로 표현, 색상으로 점수구간 구분
- **표본 개요·표본오차**(매트릭스 화면 상단, `db.computeSurveySampleSummary`): 총 응답 건수,
  이해관계자 그룹별 건수, 95% 신뢰수준 표본오차(여론조사 표준 방식, p=0.5 최악의 경우 가정)를
  표시. 표본이 10명 미만이면 경고 문구 추가. n=9 기준 ±32.7%p로 계산식이 정확히 일치하는 것을
  검증

## [1.3.0] - 2026-08-14

지난 버전에서 제안했던 아이디어 중 1번(응답 소요시간)을 제외한 3개를 구현하고, 매트릭스 원 크기를
순위 기반으로 조정했습니다.

### 신규
- **매트릭스 신뢰구간 시각화**(`db.computeMatrixConfidence`): 테마그룹별 영향/재무 축에 실제 기여한
  개별 응답 점수로 표준오차(SEM)와 95% 신뢰구간을 계산, 매트릭스에 흐린 점선 원으로 표시 —
  표본이 작을수록 원이 커져 "이 위치는 아직 불확실하다"를 시각적으로 전달
- **매트릭스 원 크기 순위화**(요청 반영): 영향+재무 합산점수가 높은 테마그룹일수록 원을 크게(최대 17px),
  낮을수록 작게(최소 8px) — 순위에 따라 선형으로 배분. 실제 데이터로 7개 지점이 17.0→8.0까지
  균등 간격으로 배분되는 것 확인
- **이해관계자 그룹 간 합의도 대시보드**(`#/consensus/:templateId`): 응답한 모든 그룹 쌍에 대해
  0~100점 합의도 점수와 가장 이견이 큰 상위 3개 문항을 표시. 종업원(평균 1.3~1.5점)과
  협력사(평균 5.0점)로 극단적으로 다르게 응답시키는 테스트에서 합의도 23점, 이견 최상위 문항까지
  정확히 산출되는 것을 확인
- **이상치 처리 이력 로그**(`#/exclusion-history/:assessmentId`): 취합승인 시 제외되는 모든 응답을
  append-only로 기록(누가·언제·어떤 응답을·왜). 평가사이클 관리 화면에서 바로 접근 가능

## [1.2.0] - 2026-08-14

응답 신뢰도 분석을 통계 기반으로 강화하고, 이상값 처리를 규칙 기반으로 조언하는 기능을 추가했습니다.
AI를 호출하지 않고 계산된 통계에 규칙을 적용하는 결정론적 방식을 유지했습니다(v2.6 원칙과 일관).

### 신규
- **응답자별 신뢰도 분석**(`db.computeRespondentReliability`): "품질점수"(성의없는 응답 여부 —
  전문항 동일점수, 낮은 변동성, 낮은 완료율 기반 0~100점)와 "관점차이"(그룹 평균 대비 개인의
  평균 이탈도, z-score 기반)를 **분리된 지표**로 계산 — 소수의견을 성의없는 응답과 혼동해 걷어내지
  않도록 설계
- **문항별 이상치 탐지**(`db.computeQuestionOutliers`): IQR(사분위범위) 방법으로 문항별 이상치를
  경미(mild)/극단(extreme)으로 구분
- **규칙 기반 처리 조언**(`db.getReliabilityAdvice`): 품질 낮음→제외 권장, 관점만 다름→소수의견
  유지+추가확인 권장, 응답자 10명 미만→표본확대 우선 권장, 특정 이해관계자 그룹에 이상치가
  몰린 경우→그룹 편중 여부 확인 권장 — 4가지 규칙을 자동 판단해 메시지 생성
- 결과취합 검증·승인(`#/signoff`) 화면을 신뢰도 테이블 + 문항별 이상치 + 처리조언 종합 화면으로 개편
- 결과분석(`#/analysis`) 화면에 신뢰도 요약 카드 및 소표본(응답자 10명 미만) 경고 추가

### 다음 버전 아이디어 (제안, 미구현)
- 응답 소요시간 캡처 → 너무 빠른 응답(수 초 내 전체 제출) 탐지
- 이해관계자 그룹 간 합의도 대시보드(그룹 쌍별 상관계수)
- 매트릭스에 신뢰구간(오차범위) 시각화 — 표본이 작을수록 점 주변에 반경 표시
- 이상치 처리 이력 로그(누가 언제 어떤 응답을 왜 제외했는지 전체 이력 조회 화면)

## [1.1.0] - 2026-08-14

설계문서 v2.0~v2.6 대비 실제 구현 상태를 전수 점검한 뒤, v2.3(7단계 흐름 보완설계)에서
빠져 있던 항목을 채우고, 업무 순서대로 메뉴를 재구성하고, 자동 오류탐지를 추가했습니다.
v2.5(ESRS 정밀형 외부설문)는 v2.6에서 이미 대체되어 삭제 대상으로 확정 — 코드에 잔재가
없음을 확인했습니다(중복 없음).

### 신규 (v2.3 공백 해소)
- **대상선정**(`#/target-selection/:assessmentId`, v2.3 2장): 선정방법·기준 서술 + 대상
  이해관계자 선택 + 승인(기준 서술 없이는 승인 불가)
- **결과취합 검증·승인**(`#/signoff/:templateId`, v2.3 5장): 전체 문항 동일점수 등
  이상응답 자동탐지 → 제외 여부 선택(제외 시 사유 필수) → 승인
- **지속가능경영보고서 반영**(`#/report/:assessmentId`, v2.3 7장): 매트릭스 결과·방법론·
  이해관계자 참여현황·IRO 근거를 AI 재작성 없이 그대로 조립해 .md로 다운로드

### 신규 (업무 파이프라인 & 자동 오류탐지, 이번 요청 반영)
- **파이프라인 대시보드**(`#/`, 신규 홈): 대상선정→설문작성→실사→취합승인→분석→매트릭스확정→
  보고서반영 7단계를 한 화면에서 진행상태(정상/권고/오류) 색상으로 보여주고, 각 단계 클릭 시
  해당 화면으로 바로 이동
- **자동 오류탐지 엔진**(`db.runWorkflowChecks`): 대상선정 미승인, 설문 미작성, 응답 없음,
  응답률 50% 미만, 이상응답 존재, 취합 미승인, 이중중대 이슈의 IRO 근거 누락, 확정 준비완료
  여부를 자동으로 점검해 파이프라인 대시보드에 표시
- 네비게이션을 업무 순서대로 재배열(①평가사이클→이해관계자→이슈풀 참고자료 순), 기존
  "설문 목록"은 `#/survey-list`로 이동해 보조 화면으로 유지

### 데이터 구조 변경 (SCHEMA_VERSION 1→2)
- `tb_target_selection`, `tb_aggregation_signoff` 테이블 추가(하위호환: 기존 저장 데이터에는
  빈 값으로 채워짐, 마이그레이션 필요 없음)

## [1.0.0] - 2026-08-14

### 정리(De-duplication)
- 같은 응답자가 같은 설문에 재제출하면 기존 응답을 지우고 새 값으로 교체(업서트)하도록 변경 —
  이전에는 재제출 시 응답이 누적되어 평균 계산이 왜곡될 수 있었습니다.
- 엑셀 일괄 업로드도 동일하게 응답자명 기준 업서트로 변경, 결과 메시지에 "신규/갱신" 건수를 구분 표시.
- 이해관계자 등록 시 동일 이름+소속구분이 이미 있으면 재등록을 막고 안내.
- `js/store.js`에 `SCHEMA_VERSION`을 도입해 저장 데이터 구조 마이그레이션을 명시적으로 관리.

### 기능 (이전까지 누적 반영된 내용을 1.0.0 기준선으로 정리)
- 이슈풀(39개, 실데이터) 기반 설문지 작성 · 응답 · 결과분석 · 사사분위 매트릭스
- 수동조정(사유 필수) 및 계산값/최종값 분리
- ESRS 1 AR16 토픽 마스터, 평가사이클(연도별) 관리, 확정(FINALIZED) 및 이월(Carry-forward)
- 이해관계자 마스터, 내부 IRO 정밀화 워크시트(기본중대 토픽 비중대 판정 시 사유 강제)
- 관리자 가중치·임계값 조정, GRI 코드·E/S/G/High-Medium-Low 등급 표기, 전년대비 New/Existing 비교
- 목표문항수 제한, E/S/G 균등선택, 랜덤선택, 구글폼 내보내기(Apps Script), 엑셀 템플릿/일괄업로드

### 알려진 제한사항 (다음 버전 후보)
- 대상선정(업체 단위) 승인 게이트, 문항 확정 승인, 취합 sign-off 등 결재 워크플로우 미구현
- 테마그룹 ↔ ESRS 토픽 매핑은 추정안(확인 필요, `js/seed-data.js` 주석 참고)

## 버전 규칙 (이번 버전부터 적용)

- `js/version.js`의 `APP_VERSION`을 Semantic Versioning으로 관리합니다.
- 데이터 구조가 바뀌면(테이블/필드 추가·변경) `js/store.js`의 `SCHEMA_VERSION`을 올리고,
  `_loadState()`의 마이그레이션 가드에 하위호환 처리를 추가합니다.
- 모든 변경은 이 파일 상단에 새 섹션으로 추가하고, 화면 하단 푸터의 버전 표시가 실제 배포본과
  항상 일치하도록 `index.html`은 손대지 않고 `js/version.js`의 상수만 갱신합니다.

## 패키징 규칙 (이번 버전부터 적용)

배포용 zip 파일명에는 항상 `js/version.js`의 `APP_VERSION`을 그대로 붙입니다
(예: `smart-esg-materiality-app-v1.0.0.zip`). 버전을 올릴 때마다 새 파일명으로 생성되므로
이전 버전 zip과 절대 덮어써지지 않고, 파일명만 보고도 어느 버전인지 바로 알 수 있습니다.
